--------------------------------------------------------
Descripción del Proyecto:
--------------------------------------------------------
Este proyecto consiste en el desarrollo de un sitio web ficticio para una empresa del sector financiero llamada "Finanzas Cardona", creado como parte del trabajo final de la asignatura.

Tecnologías utilizadas:
- HTML5
- CSS3

--------------------------------------------------------
Estructura del Sitio:
--------------------------------------------------------
1. index.html        → Página de inicio con 3 secciones (Consultoría, Préstamos, Educación)
2. productos.html    → Galería de productos financieros con botón "Ver más"
3. presupuesto.html  → Formulario con validación de datos (pattern + checkbox)
4. contacto.html     → Mapa y datos de contacto
5. aviso.html        → Página de aviso legal
6. info.html         → Mensaje académico mostrado desde botones “Ver más”
7. gracias.html      → Confirmación de envío de formulario con mensaje académico

--------------------------------------------------------
Recursos Incluidos:
--------------------------------------------------------
- Carpeta /img       → Imágenes de productos, iconos, logotipo y favicon
- Carpeta /css       → estilos.css con todos los estilos aplicados
- favicon.ico        → Icono de pestaña del navegador
- readme.txt         → Este archivo
